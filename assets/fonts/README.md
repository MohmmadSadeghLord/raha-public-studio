# فونت‌های قالب

فونت‌های موردنیاز در همین پوشه همراه قالب قرار دارند و هنگام استقرار باید به همان مسیر منتقل شوند:

```text
assets/fonts/
├── vazirmatn/
│   ├── Vazirmatn-Regular.woff2
│   ├── Vazirmatn-Bold.woff2
│   └── Vazirmatn-Black.woff2
└── sahel/
    ├── Sahel.woff2
    ├── Sahel-Bold.woff2
    └── Sahel-SemiBold.woff2
```

فایل‌های وزن‌های دیگر Sahel نیز در پوشه موجودند. آدرس فونت‌های محلی در `assets/css/base.css` تعریف شده است. پس از انتقال قالب، صفحهٔ سفارش و حساب کاربری را باز کن و بارگذاری فایل‌های `.woff2` را در ابزار شبکهٔ مرورگر بررسی کن.
